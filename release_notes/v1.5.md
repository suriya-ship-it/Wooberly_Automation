# Release Notes - v1.5 (Full Trip Lifecycle, In-Ride Chat, Toll, Cash & Dual Reviews)

## Overview
Release v1.5 extends the Wooberly Parallel Driver & Rider automation flow from initial booking dispatch and acceptance to the entire post-booking ride lifecycle, including pickup location arrival, in-ride rider/driver chat messaging, ride commencement with OTP verification, trip completion, toll fee submission, cash payment confirmation synchronization, and mutual 5-star rating/reviews.

---

### Infrastructure & Stability Improvements
- **Connection Refused Fix (`ECONNREFUSED`)**: WebdriverIO now explicitly targets `hostname: '127.0.0.1'` instead of `localhost` to prevent IPv6 (`::1`) loopback connection failures on macOS.
- **Self-Healing Appium Server**: Added `ensureAppiumServer()` which checks `http://127.0.0.1:4723/status` and automatically starts a background Appium process if not running.
