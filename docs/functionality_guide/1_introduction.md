# 1. Introduction & Technology Stack

Wooberly is a comprehensive on-demand taxi business solution comprising a Rider App, a Driver App, and an Admin Panel. 

## Technology Stack

### Mobile Apps (iOS and Android)
- **Framework**: Flutter (Dart language)
- **Networking/API**: GraphQL schema, Adhara Socket IO
- **Services**: Firebase, Google Maps, and Geocoder

### Backend (Admin & API)
- **Runtime & Server**: Node.js, Express.js
- **Database**: MySQL with Sequelize ORM
- **API**: GraphQL

### Frontend (Admin Web Panel)
- **Framework**: React, Redux
- **Styling**: Bootstrap
- **API Integration**: React Apollo and Apollo Client
